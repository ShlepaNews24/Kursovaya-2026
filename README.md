1. Работа с данными через LINQ
В рамках первого задания была реализована логика выборки и обработки данных на стороне сервера. Использовались запросы LINQ для работы с коллекциями игр.
Фильтрация списка игр по жанрам, рейтингу и году релиза. Реализована сортировка (по популярности и дате добавления). Настроена группировка игр для вывода статистики (например, «Топ-5 игр в жанре RPG»).
Пользователь получает релевантный список игр без загрузки лишних данных из базы, что оптимизирует производительность.

2. Система обработки исключений и валидации
Для обеспечения стабильности работы сайта была внедрена система кастомных исключений и валидации данных.
Созданы собственные классы ошибок (например, `GameNotFoundException`, `UserAlreadyExistsException`). Настроена проверка входящих данных: рейтинг игры не может быть больше 10 или меньше 0, обязательные поля (название, описание) не могут быть пустыми. Настроено логирование ошибок в файл для последующего анализа.
Приложение не «падает» при некорректных действиях пользователя, а выдает понятные сообщения об ошибках.

4. Асинхронное программирование
Для повышения отзывчивости интерфейса и пропускной способности сервера весь код работы с базой данных и внешними сервисами переведен в асинхронный режим.
Использование паттерна `async/await` во всех контроллерах и сервисах. Реализована параллельная загрузка тяжелых ресурсов (например, списка игр и списка скриншотов к ним одновременно через `Task.WhenAll`). Внедрена поддержка отмены длительных операций (CancellationToken).
Сервер может обрабатывать больше одновременных запросов, а интерфейс не блокируется при длительных операциях.

5. Работа с потоками (Streams) и файлами
Реализован функционал загрузки и обработки медиа-контента (скриншотов и аватарок).
Написан сервис для сохранения файлов на сервере с использованием `FileStream`. Реализована генерация миниатюр (thumbnails) для превью игр с использованием `MemoryStream` (изображение загружается в память, уменьшается и сохраняется). Использован `BufferedStream` для оптимизации чтения/записи больших файлов.
Администратор может загружать обложки игр, которые автоматически сжимаются и сохраняются на диск.

5. Сетевое программирование и API
Разработана архитектура взаимодействия клиентской и серверной части, а также интеграция с внешними сервисами.
Создан RESTful API для предоставления данных о играх в формате JSON (для потенциального мобильного приложения или SPA-фронтенда). Настроен `HttpClient` для обращения к внешнему игровому API (например, IGDB) для автоматического подтягивания описания и обложек новых игр.
Сайт может автоматически обновлять информацию об играх из внешних источников, а также предоставляет доступ к своим данным через API.

6. Работа с БД через ADO.NET
Для выполнения специфических задач и оптимизации сложных запросов был использован низкоуровневый доступ к базе данных.
Написаны прямые SQL-запросы для получения сложной статистики (например, сводная таблица по продажам или популярности). Реализованы транзакции: при добавлении игры, если происходит ошибка при сохранении картинки, запись в базе данных откатывается (rollback), обеспечивая целостность данных (ACID).
Обеспечена надежность данных и возможность выполнения сложных аналитических выборок.

7. ORM Entity Framework Core
Основной слой работы с данными переведен на использование объектно-реляционного маппинга.
Настроена конфигурация базы данных через подход Code First. Созданы модели данных (Game, Genre, Review) и настроены связи между ними (One-to-Many, Many-to-Many). Реализованы миграции для обновления схемы БД. Настроен `DbContext` для управления сессиями.
Разработчик работает с объектами C#, а не с SQL-таблицами, что ускоряет разработку и снижает количество ошибок.

8. Разработка десктоп-приложения (WPF)
Создан отдельный клиент для администрирования сайта.
Разработан интерфейс на XAML для управления контентом. Реализована привязка данных (Data Binding) для отображения списка игр. Настроены стили и шаблоны элементов управления. Приложение подключается к тому же API, что и веб-сайт. Администратор имеет удобный десктопный инструмент для добавления и редактирования игр без необходимости заходить в веб-интерфейс
